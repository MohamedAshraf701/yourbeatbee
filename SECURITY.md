# Security Policy

If you discover a security vulnerability in YourBeatBee, please report it privately so we can address it before disclosing publicly.

Preferred reporting methods:

1. Create a private security advisory on GitHub: https://github.com/orgs/MohamedAshraf701/security/advisories (or the repository "Security" tab → "Security advisories").
2. If you cannot use GitHub advisories, send an email to: security@yourbeatbee.dev (replace with a real contact address).

What to include:

- A clear description of the vulnerability
- Steps to reproduce
- Impact assessment and any PoC if available
- A suggested patch or mitigation, if you have one

We will respond within 7 business days and work with you to patch the issue.

Note: Do not disclose the issue publicly until a fix has been released.
